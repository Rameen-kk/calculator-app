# Digital Calculator 🧮

A simple, responsive calculator built with HTML, CSS & JavaScript. 

**Live Demo:** https://rameen-kk.github.io/calculator-app/

### **Features:**
- Basic operations: +, -, ×, ÷, %
- Clear & Delete functionality 
- Responsive design - works on mobile & desktop
- Clean dark theme UI

### **Tech Stack:**
- HTML5
- CSS3 - Grid & Flexbox
- Vanilla JavaScript

### **How to use:**
1. Click numbers to input
2. Select operator 
3. Press = to calculate
4. C to clear, ⌫ to delete last digit
